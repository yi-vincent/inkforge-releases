# 墨坊 InkForge

**一个人也能日更，还像你自己写的。**

热点选题、写稿、去套话、排版配图、多平台发布，墨坊在你的电脑上一口气做完。你只管挑题，再亲手改最后一遍。

官网：https://inkforge.ailinko.cn　·　全功能免费试用，不用注册，文章只存在你的电脑

## 能做什么

- **热点选题**：10 个平台热榜和 50 多个 RSS 源实时汇总，按你每个号的定位挑出值得写的题，看一眼热度走势就知道该不该追。
- **一键成稿**：研究、找素材、搭框架、写初稿、去套话、配图排版，自动接力。你去倒杯水，回来改一遍就能发。
- **像你自己写**：给每个号设定作者人设，口吻、习惯和禁忌都记住；也可以拿你写过的文章，建一个和你声音接近的人设。
- **排版模板**：每个号一套专属排版，新文章自动套用，读者一眼就认得出是你。
- **内容中心**：所有号的稿子放在一处，在线改稿、预览，选好账号一键发出去。
- **资源图库**：封面和配图生成就入库，随用随取。
- **专家赛道**：30 多个内置赛道，预设目标读者、语气和禁用词，同时写好几个号，每个号的口吻都不会串。
- **数据复盘**：每个号这周写了几篇、每篇花多久、哪天断更了，一屏看完。

支持发布到：微信公众号、小红书、今日头条、百家号，以及知乎、微博（实验性）。

## 下载

最新版本：**[Releases → Latest](https://github.com/yi-vincent/inkforge-releases/releases/latest)**，在 Assets 里按电脑选一个：

| 文件 | 适用 |
|---|---|
| `InkForge-<版本>-mac-arm64.dmg` | macOS 12+，Apple 芯片（M1–M4）。「关于本机」里写着「芯片」 |
| `InkForge-<版本>-mac-x64.dmg` | macOS 12+，Intel 芯片。「关于本机」里写着「处理器」 |
| `InkForge-<版本>-win-x64.exe` | Windows 10 / 11 64 位。SmartScreen 提示时点「更多信息 → 仍要运行」 |

macOS 首次打开：Finder 里右键 → 打开，或「系统设置 → 隐私与安全性」点「仍要打开」。

每个版本的 SHA-256 校验和见官网 https://inkforge.ailinko.cn/#download 。购买授权与使用说明也在官网。
